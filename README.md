# Пешком по графу (graph.2gis.ru)

Спецпроект 2ГИС: интерактивный музей одной инженерной задачи — как довести человека из точки А в точку Б.
Статьи из «Техники — молодёжи» и «Науки и жизни» 1938–1984 годов и работа инженеров 2ГИС сегодня.

Адрес: https://graph.2gis.ru

## Как устроено

- `index.html` — готовая страница, её отдаёт GitHub Pages. Руками не править.
- `assets/` — шрифты SB Sans Text, логотип, архивные сканы, картинка превью `og.jpg`.
- `source/template.html` — исходник страницы (вся вёрстка, стили и скрипты).
- `source/build.py` — сборка: `python3 source/build.py` из корня репозитория.

Сайт статический, без бэкенда и базы данных. Посещаемость считает Яндекс Метрика (счётчик 114012584, с Вебвизором и картой кликов).
Достижения посетителя хранятся только в его браузере (localStorage).

- `404.html` — страница ошибки. Написана вручную, сборка её не трогает. Пути от корня сайта, поэтому полностью работает на домене.

## Подключение домена

DNS: `graph.2gis.ru. CNAME olesiabositi-hub.github.io.`
Затем в Settings → Pages указать Custom domain `graph.2gis.ru` и включить Enforce HTTPS.
